# 🏠 Keyd-Hanti: Online Real Estate Marketplace (Test Version)

Keyd-Hanti waa nidaam loogu talagalay in lagu maamulo laguna soo bandhigo guryaha, dhulka, iyo naqshadaha guryaha (House Plans). Kani waa **Test Version (Prototype)** 
---

## 📋 Qaybaha Hadda Shaqaynaya (Current Features)
Waxa aan dhisnay hadda waa laf-dhabarta nidaamka (MVP):

* **User Authentication:** Nidaamka diiwaangelinta (`Register`) iyo gelitaanka (`Login`) oo leh heerar kala duwan (Admin & User).
* **Property Management:** Awoodda lagu soo gelin karo hantida cusub iyadoo la raacayo qaybaha: House, Land, iyo Plan.
* **Approval System (Admin Control):** Guri kasta oo cusub ma soo baxayo ilaa Admin-ku uu ka dhigo `Approved`.
* **Dynamic Search & Filter:** Shaandheynta hantida iyo raadinta magaca si fudud.
* **Admin Dashboard:** Tirakoobka guud ee hantida iyo dadka isticmaala nidaamka.

---

## 🚀 Qorshaha Mustaqbalka (Future Scope - Real Version)
Si nidaamkan loogu beddelo ganacsi dhab ah, waxaa qorshaysan:

1.  **Buyer Dashboard:** Meel macaamilka u gaar ah oo uu ku arko dalabaadkiisa.
2.  **Integrated Payments:** Ku xiridda nidaamyada lacagta (EVC Plus, e-Dahab, Sahal) si iibka loo dhammaystiro.
3.  **Advanced Gallery:** Guri kasta in loo soo geliyo sawirro badan oo tayo leh.
4.  **Google Maps Integration:** In la muujiyo goobta saxda ah ee uu gurigu ku yaallo khariidadda.

---

## 🛠️ Tiknoolajiyada La Isticmaalay (Technical Stack)
* **Frontend:** HTML5, CSS3.
* **Backend:** PHP (Procedural & Session Management).
* **Database:** MySQL (Relational Database).
* **Version Control:** Git & GitHub.

---

## 📊 Database Structure (Table Names)
* **`users`**: Kaydinta xogta isticmaaleyaasha (ID, Username, Email, Password, Role).
* **`properties`**: Kaydinta macluumaadka guryaha (ID, Title, Category, Price, Image, Status).
